A SITE THAT KEEPS GROWING

讓溫柔，持續生長。

這不只是一個完成的網站，更是一套讓 AI 可以遵循、擴充、維持一致品質的開發方法。

01

先閱讀 AGENTS.md

AI 開始工作前，先了解網站目的、可愛手繪插畫風、固定導覽、資料結構與安全語氣。

AGENTS.md
02

依照資料格式新增文章

將新的療癒文章加入 data/articles.json，包含唯一 slug、分類、摘要、標籤、插畫路徑 illustration 與至少兩個章節。不需複製 HTML。

data/articles.json
03

由共用模板自動顯示

首頁卡片、插畫封面、搜尋、篩選及文章頁會從同一份 JSON 讀取內容，維持一致設計。

index.html + article.html
04

驗證、測試、部署

執行驗證腳本，檢查搜尋、分類、文章連結與手機版，再上傳 GitHub Pages。

python scripts/validate_articles.py
✿

試著請 AI 接續開發

「請先閱讀 AGENTS.md，依照相同的資料格式、SVG 插畫規則和溫暖語氣，在網站新增一篇『如何練習設立界線』的文章。請驗證資料並確認首頁搜尋可找到它。」

為什麼這符合這次作業？

因為新增文章時不需重畫整個網站。AI 可以依照 清楚、可驗證、可重複使用 的規則，安全且一致地增加內容，這正是 AGENTS.md 的用途。
